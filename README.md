# 아키네이터의 비밀 · 웹 활동지

경남형 AI·디지털 정보교육 수업모형 **「아키네이터의 비밀」**(중1 정보 · 알고리즘과 프로그래밍, 8차시)의 활동지 1~8을 웹에서 할 수 있게 만든 사이트입니다.
깃허브 페이지에 올리면 학생은 주소 하나로 접속하고, 제출 내용은 선생님의 구글 시트에 모입니다.

---

## 폴더 구성

| 파일 | 하는 일 |

## 설치 순서 (처음 한 번, 약 15분)

### 1단계. 공유 시트 만들기
1. `공유시트_템플릿.xlsx`를 구글 드라이브에 올립니다.
2. 파일을 열고 **파일 › Google 스프레드시트로 저장**을 누릅니다. (이제부터 이 구글 시트를 씁니다)
3. 시트 공유 범위는 **선생님만**으로 둡니다. 학생에게 시트를 공유할 필요가 없습니다.

### 2단계. 연동 코드 넣고 배포하기
1. 구글 시트 메뉴 **확장 프로그램 › Apps Script**를 엽니다.
2. 처음 보이는 코드를 모두 지우고 `apps-script/Code.gs` 내용을 그대로 붙여 넣습니다.
3. 맨 위 `TEACHER_KEY = '여기에-비밀번호를-정하세요'`를 **선생님만 아는 비밀번호**로 바꾸고 저장합니다.
4. 오른쪽 위 **배포 › 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 설명: 아키네이터
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르고 권한을 허용합니다. (‘확인되지 않은 앱’ 안내가 나오면 고급 › 이동을 누릅니다)
6. 나타난 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> 학교 구글 워크스페이스 계정에서 ‘모든 사용자’가 보이지 않으면, 관리자가 외부 공개를 막아 둔 것입니다. 개인 구글 계정으로 시트를 만들거나 학교 관리자에게 문의하세요. 학생은 로그인하지 않고 제출하므로 ‘모든 사용자’여야 합니다.

### 3단계. 설정 파일에 주소 넣기
`assets/config.js`를 열어 복사한 주소를 넣습니다.

```js
APPS_SCRIPT_URL: "https://script.google.com/macros/s/……/exec",
```

학급 수(`CLASSES`), 모둠 수(`GROUPS`), 모둠 안 번호 최대값(`MAX_NUMBER`)도 학교에 맞게 바꿉니다.

### 4단계. 깃허브에 올리고 페이지 켜기
1. 깃허브에서 **New repository** → 이름 예: `akinator` → **Public** → Create.
2. **Add file › Upload files**에서 이 폴더 안의 파일과 폴더를 **모두** 끌어다 놓고 **Commit changes**.
   - `index.html`이 저장소 맨 위(루트)에 있어야 합니다.
3. 저장소 **Settings › Pages** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save.
4. 1~2분 뒤 `https://<깃허브아이디>.github.io/akinator/` 주소가 생깁니다. 이 주소를 학생에게 안내합니다. (QR 코드로 만들면 편합니다)

### 5단계. 확인
- 학생 화면에서 아무 활동지나 쓰고 **제출하기** → 구글 시트 ‘제출’ 탭에 한 줄이 생기면 성공입니다.
- `teacher.html`에서 2단계의 비밀번호로 들어가 제출 현황이 보이는지 확인합니다.

> **Apps Script 코드를 고친 경우**에는 배포 › 배포 관리 › 연필 › 버전: **새 버전** › 배포를 해야 반영됩니다. (주소는 그대로)

## 수업에서 쓰는 법

### 학생
1. 주소 접속 → 학급·모둠·번호 고르기 (이름·학번은 쓰지 않습니다)
2. 활동지를 작성하면 **그 기기에 자동 저장**됩니다. 새로고침해도 남아 있어요.
3. 수업이 끝나면 **제출하기**. 다시 고쳐서 제출하면 최신 내용으로 바뀝니다.
4. 다른 기기에서 이어 쓸 때는 화면 아래 **내 제출 불러오기**를 누릅니다.
5. 모둠 활동지(2·4·6·7·8)는 한 명이 대표로 쓰고 제출한 뒤, 다른 모둠원이 **모둠 친구 제출 불러오기**로 같은 내용을 받을 수 있습니다.

### 활동지별 웹 기능

| 활동지 | 종이 활동 | 웹에서 하는 방식 |
|---|---|---|
| 1 | 업다운 3판 기록, 반 전체 표·막대그래프 | 부른 수를 적으면 질문 수 자동 계산, **컴퓨터와 게임** 버튼, 반 전체 기록 불러오기, 이상치·결측치 빨간 줄 표시, “이상한 기록 빼고 계산” 막대그래프 |
| 2 | 좋은/나쁜 질문, 특징 표, 입력·처리·출력, 조사 계획, AI 검증 | 특징 표 칸을 눌러 1/0 입력, 예의 수 자동 계산, 줄 추가 |
| 3 | 챔피언전, 전략 발견, 의사코드·순서도 빈칸, 사람 컴퓨터 | 계산 칸·의사코드·순서도 **확인하기**, 순서도 빈칸에 직접 입력, +1/−1을 빼고 실행해 보는 **실행 확인 도구** |
| 4 | 알고리즘 비교표·선그래프, 뒤섞인 카드, 결정 트리, AI 검증 | 표를 채우면 선그래프 자동, 반 평균 그래프, **카드 뒤집기**(뒤섞인/정렬된), **결정 트리 만들기 도구**(질문을 고르면 동물별 질문 수·평균 자동 계산), 2의 거듭제곱 계산기 |
| 5 | 설계서→블록 대응, 테스트, 예외 처리, 함수, +1·−1 실험 | 예측·실제 순서가 같은지 자동 표시, 예외 처리 따라가기 **확인** |
| 6 | 리스트 계획, 질문 순서 A/B 비교, 버그 기록 | 항목수가 같은지 자동 점검, 합계·평균·최대 자동 계산 |
| 7 | 사용자 테스트 기록, 약점 찾기, 규칙 vs AI, 재테스트 | 정답 ○/× 자동, 정답률·평균 질문 수 자동, 틀린 경우 자동 모음, 모둠별 정답률 그래프 |
| 8 | 발표 준비, 동료 평가, 확장·윤리 토의, 성찰 | 활동지 6·7 숫자 **가져오기**, 동료 평가가 상대 모둠에 전달되고 **받은 피드백 보기** |

### 선생님 (`teacher.html`)
- **제출 현황**: 학생 × 활동지 표. ‘✔ 보기’를 누르면 학생 활동지를 그대로(읽기 전용) 엽니다.
- **1·3차시 게임 기록 / 4차시 알고리즘 비교 / 4차시 결정 트리 / 7차시 사용자 테스트 / 8차시 동료 평가**: 반 전체 그래프와 표
- **교사용 예시 답**: 활동지별 예시 답과 그림
- **엑셀 내려받기**: 불러온 학급 자료를 탭별로 묶은 .xlsx 파일

## 체험 모드
`APPS_SCRIPT_URL`을 비워 두면 **체험 모드**로 동작합니다. 제출 내용이 그 기기(브라우저)에만 저장되므로, 수업 전에 선생님 혼자 모든 기능을 미리 해 볼 수 있습니다. 체험 모드의 선생님 비밀번호는 `config.js`의 `DEMO_TEACHER_KEY`(기본 1234)입니다.

## 개인정보와 보안
- 학생 실명·학번은 저장하지 않습니다. 학급·모둠·번호만 씁니다. (활동지에도 친구 이름 대신 번호를 쓰도록 안내되어 있습니다)
- 구글 시트는 선생님 계정에만 있고, 학생은 시트에 직접 접근하지 않습니다.
- 학생 화면에서 읽을 수 있는 것은 반 전체 통계용 숫자(게임 기록 등)와 같은 모둠의 제출 내용, 우리 모둠이 받은 동료 평가뿐입니다. 모든 학생의 활동지 원본은 교사 비밀번호로만 볼 수 있습니다.
- 교사 비밀번호는 Apps Script에만 저장되고 깃허브 코드에는 들어가지 않습니다.

## 자주 묻는 질문
- **제출이 안 돼요** → `config.js` 주소 끝이 `/exec`인지, 배포의 액세스 권한이 ‘모든 사용자’인지 확인하세요.
- **다른 기기에서 이어서 쓰고 싶어요** → 먼저 쓰던 기기에서 **제출하기**를 누른 뒤, 새 기기에서 같은 학급·모둠·번호로 들어가 화면 아래 **내 제출 불러오기**를 누르면 됩니다.
- **엔트리 작품은?** → 5~7차시 프로그램은 엔트리(playentry.org)에서 만들고, 웹 활동지에는 기록만 남깁니다.
